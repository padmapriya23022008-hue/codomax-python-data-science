# Air Quality Analysis Using Python

## Project Overview
This is a beginner-level Data Science mini-project that analyzes sample Air Quality Index (AQI) values for five Indian cities using Python.

## Objectives
- Display AQI values for different cities.
- Calculate the average AQI.
- Identify the city with the highest AQI.
- Find cities with AQI values above 100.

## Technologies Used
- Python 3
- Dictionaries
- Loops and conditional statements
- GitHub

## Sample Dataset
| City | AQI |
|---|---:|
| Chennai | 85 |
| Delhi | 160 |
| Mumbai | 72 |
| Bengaluru | 48 |
| Hyderabad | 110 |

## Results
- Average AQI: 95.0
- Highest sample AQI: Delhi (160)
- Cities with AQI above 100: Delhi and Hyderabad

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Run the following command:
   python air_quality_analysis.py

## Dataset Disclaimer
These AQI values are sample values for educational purposes only. They are not verified real-time measurements.

## Learning Outcomes
Practiced Python dictionaries, loops, conditions, calculations, and basic data analysis.
